# Imperio Maderero 3D: Idle Tycoon

Primera versión jugable del tycoon maderero en 3D, construida como aplicación web estática.

## Ejecutar
Abre `index.html` en un navegador moderno con conexión a internet. Three.js se carga desde jsDelivr.

## Controles
- PC: WASD o flechas.
- Móvil: joystick táctil.
- Mantén **TALAR** junto a un árbol.
- **ENTREGAR** cerca de la banda del aserradero.
- **VENDER** cerca del puesto de venta.
- **MEJORAS** para comprar capacidad, hacha, valor de tablas y trabajadores.

## Guardado
El progreso se guarda localmente en el navegador. Aún no se sincroniza entre dispositivos.

## Publicación
Se incluye un workflow de GitHub Actions para publicar en GitHub Pages. En Settings → Pages, selecciona **GitHub Actions** como fuente si todavía no está configurada.

## Estado
MVP inicial: movimiento 3D, tala, recolección, árboles regenerables, entrega, procesamiento temporizado, venta, mejoras y trabajadores automáticos. Próximas etapas: camión y rutas logísticas visibles, máquinas animadas, parcelas desbloqueables, oficinas, eventos de inversor, pruebas de rendimiento y monetización publicitaria.
